# Choiser

Choiser is a production-ready Next.js web app that helps users decide what to do, play lightweight games, and use practical utility tools through a polished dark interface.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion

## Scripts

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run typecheck`

## Notes

The local environment available during setup ships with Node 18, while Next.js 16 requires Node 20.9 or newer. To keep the project runnable without changing the system installation, the package scripts invoke a project-local Node 22 binary provided by the `node` package.
